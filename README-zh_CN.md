## 🚧 在做的项目

### 🤖 [YSU2026 RoboMaster Sentry](https://github.com/tungchiahui/ysu2026_rm_sentry)

基于 **ROS 2 Humble + Nav2 + 激光雷达 SLAM** 的 RoboMaster 哨兵机器人自主导航软件栈。\
目前的工作包括机器人描述与 TF、Livox Mid-360 集成、导航调参、定位、STM32 与 ROS 2 通信，以及实机部署。

### 🔌 [Serial_Pack](https://github.com/tungchiahui/Serial_Pack)

一套可复用的通信软件栈，用于连接嵌入式控制器和 ROS 2 系统。\
使用 **C++23 和 Boost.Asio**，支持异步串口通信、自定义二进制帧、CRC16 校验与 ROS 2 集成。

### 🧭 [CyberNaviRobot](https://github.com/CyberNaviRobot)

自主开发的麦克纳姆轮移动机器人，用于建图、定位与自主导航。

- [ROS 2 Jazzy 上位机工作空间](https://github.com/tungchiahui/CyberRobot_ROS2_Jazzy_WS)
- [STM32 + FreeRTOS 主控](https://github.com/tungchiahui/CyberRobot_STM32_FreeRTOS)
